## Подключение

1. Включите Bluetooth на компьютере. На значке откройте Bluetooth/QR-экран.
2. Отключите значок в ZRun и на сайте, если они уже держат соединение.
3. Нажмите **Подключить**. Выберите устройство в списке.
4. Сохраните понятное имя. Если ОС скрывает MAC, введите адрес с экрана значка или вставьте содержимое его QR-кода. Ссылка разбирается локально и не открывается.
5. Выберите контент, проверьте круглый предпросмотр и нажмите **На значок ↗**. Держите значок рядом до окончания передачи.

При нескольких одинаковых E87 включайте режим подключения по одному, назначая каждому имя. Приложение не выбирает первое попавшееся устройство автоматически.

macOS отдаёт UUID, из которого Chromium формирует служебный ID, внешне похожий на MAC. Этот ID не является аппаратным MAC. Приложение показывает ID отдельно и явно помечает адрес, сохранённый пользователем. На Mac отдельный локальный помощник читает адрес из manufacturer data E87 (0x6DB9), когда прошивка его передаёт. Этот формат объявления проверен на E87 с экраном 360 × 360. Для неизвестных форматов остаётся ручной ввод. Служебный ID никогда не выдаётся за аппаратный MAC. Windows/Linux могут отдавать адрес напрямую; он показывается, если ID имеет формат MAC. Сохранённые привязки действуют на этом компьютере; при изменении ID их может потребоваться задать заново. «Забыть» удаляет только запись в приложении, не данные на значке.

## Файлы

| Режим | Вход | Что передаётся |
| --- | --- | --- |
| Картинка | PNG, JPEG/JPG, WebP, BMP; GIF как один статичный кадр | JPEG |
| Слайд-шоу | Несколько картинок, упорядоченных по имени с числовой сортировкой | AVI / Motion JPEG |
| Видео | Рекомендуется MP4/H.264 или WebM/VP8/VP9 | AVI / Motion JPEG без звука |
| Бегущая строка | Текст до 80 символов, кириллица; шрифт, размер, цвет, фон, скорость и направление | AVI / Motion JPEG |
| Эффекты | 8 новых материалов Studio и 12 классических генераторов | JPEG или AVI |
| QR-код | Текст ссылки | JPEG |

- До подключения размер кадра — 368 × 368. После подключения размер запрашивается у значка.
- Важные элементы должны помещаться в круг. Картинку можно двигать мышью и масштабировать колесом.
- Готовая передача ограничена **2 000 000 байт** (около 1,91 МиБ), исходный файл может быть больше.
- Видеофрагмент — до 10 секунд. Если результат велик, уменьшите длительность или частоту кадров. Для начала удобно 12 fps.
- В слайд-шоу 1 fps означает один кадр в секунду. Имена `01.png`, `02.png`, `03.png` помогают задать порядок.
- MOV, HEVC и другие кодеки зависят от декодеров Chromium/ОС; расширение файла само по себе не гарантирует совместимость. Перекодируйте неподдерживаемый ролик в MP4/H.264.
- **Сохранить** экспортирует подготовленный JPEG/AVI. Это не экспорт редактируемого проекта. AVI можно выбрать в режиме видео, если системный декодер его поддерживает.
- ZIP, JSON, программы и исполняемые «сценарии» не загружаются. Анимация здесь — последовательность кадров.

## Бегущая строка и коллекция Studio

Текст движется влево или вправо; доступны гротеск, антиква и моноширинный шрифт, размер 48–120 px, три скорости, цвет и свечение. Предпросмотр обновляется после ввода. Цикл ограничен 240 кадрами при 15 fps; если надпись длинная, приложение предложит увеличить скорость, уменьшить размер или сократить текст.

Новые эффекты: **Liquid chrome**, **Pearl**, **Crimson silk**, **Aurora**, **Dichroic**, **Gold eclipse**, **After dark** и **Contour**. Это локально генерируемые циклы, а не скачанные видео. Выберите 3, 5, 6 или 8 секунд; для статичного аксессуара переключитесь на «Кадр». Классические 12 эффектов доступны отдельно.

Основное окно — 920 × 720, справка спрятана под «?», сохранённые MAC и имена — под «Значки».

## Установка и платформы

- **macOS:** откройте DMG и перенесите E87 Studio в Applications либо запустите готовый `.app`. При первом подключении macOS запросит доступ к Bluetooth. Сборка локально подписана ad hoc, без платного Developer ID и нотариализации.
- **Windows x64:** установщик `*-setup.exe` либо `*-portable.exe`. Нужен BLE-адаптер и подходящий драйвер. Сборка не подписана коммерческим сертификатом.
- **Linux x64:** AppImage или DEB. Нужны работающий BlueZ, D-Bus и BLE-адаптер. На Linux поддержка Web Bluetooth зависит от дистрибутива; приложение включает необходимую экспериментальную возможность Chromium. Sandbox остаётся включён. Если AppImage не запускается из-за FUSE, используйте DEB или стандартный режим извлечения AppImage. Не отключайте sandbox.

Подключение и определение адреса проверены на macOS / Apple Silicon. Установку, декодирование видео и реальную Bluetooth-передачу на Windows/Linux нужно проверить на соответствующих системах; успешная упаковка не заменяет эту проверку.

## Разработка и сборка

Нужны Node.js 22.16+ и npm. На macOS для сборки помощника чтения MAC нужны Xcode Command Line Tools (Swift); в готовом приложении ничего дополнительно устанавливать не нужно. Интернет нужен только для установки зависимостей и скачивания Electron при сборке.

```sh
npm ci
npm run check
npm start
```

`npm run build:web` собирает исходный веб-редактор в `web/dist/`. Настольная сборка использует `web/desktop.html` и `web/dist-desktop/`; веб-интерфейс и протокол upstream сохранены.

`npm start` собирает настольный интерфейс и запускает Electron. Открывать localhost или отдельно устанавливать Chrome не требуется.

Сборка установщиков на соответствующей платформе:

```sh
npm run dist:mac
npm run dist:win
npm run dist:linux
```

Готовые файлы — в `release/`. На Mac по умолчанию собирается архитектура текущего компьютера. Для обеих архитектур Mac:

```sh
npm run build
npx electron-builder --mac --universal --publish never
```

`.github/workflows/desktop.yml` проверяет PR и позволяет запустить сборку вручную: macOS universal (Intel + Apple Silicon), Windows x64 и Linux x64. Он собирает и сохраняет артефакты, не публикует релизы. В fork можно вручную запустить **Desktop installers** на нужной ветке. Публикация в Releases выполняется отдельно после проверки сборок.

Ключевые файлы: `desktop/main.cjs` (Electron, разрешения, Bluetooth), `desktop/selection.cjs` (жизненный цикл поиска), `web/src/studio/` (отдельный настольный интерфейс и генераторы), `web/src/lib/e87-protocol.ts` (общий исходный протокол).

## Если значок не находится

Оставьте на нём QR-экран, проверьте Bluetooth и системное разрешение для E87 Studio. Завершите другое соединение со значком. Повторный поиск запускается кнопкой подключения; автоматически приложение не сканирует. Поиск отменяется через две минуты. Раскройте журнал внизу окна, чтобы увидеть подробности ошибки.

## Устройство кода

Electron открывает только локальный интерфейс. Renderer работает с sandbox и context isolation, без Node.js. Preload разрешает лишь выбор Bluetooth-устройства и подтверждение сопряжения. На Mac маленький Swift-помощник сканирует объявления и передаёт адреса основному процессу через JSON; он не загружает файлы на значок. Общий протокол BLE, авторизация Jieli и создание AVI используются из upstream без изменений.

Тесты проверяют выбор среди нескольких устройств, отмену и устаревшие ответы, тайм-аут, различие MAC и служебного ID, разбор QR и ограничение длины бегущей строки. Они не заменяют аппаратную проверку. Исходная документация протокола полностью сохранена в [docs/PROTOCOL.md](docs/PROTOCOL.md).
